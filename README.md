- Sage Eatery

- Developed by: Likamva Dzengwa
- Student Number: ST10472125

Sage Eatery is a modern, earthy-themed restaurant website that showcases a locally inspired menu with a strong focus on sustainability and community.  
The platform allows users to browse through starters, main courses, and desserts — all curated by internationally renowned chef Christoffel, known for his refined approach to free-range produce and farm-to-table cooking.  

This interactive menu system enables users to explore dishes, view details, and manage menu items dynamically.



- Target Market

Sage Eatery is designed for:
- Eco-conscious diners who value locally sourced, free-range produce.  
- Food enthusiasts interested in seasonal, handcrafted meals.  
- Patrons looking for a digital platform to explore restaurant offerings before visiting.  
- Restaurants wanting an adaptable and modern menu presentation system.

- Features

- View menu items by course: Starters, Mains, and Desserts.  
- Add or remove dishes dynamically.  
- See dish descriptions, prices, and images.  
- Navigation between pages.  


- Tech Stack

- React Native (Expo) – App framework  
- TypeScript / JavaScript (TSX)** – For type safety and cleaner component logic  
- React Navigation – Page routing and navigation management  
- Custom Context API – For state and data management across pages  
- Styling: Native StyleSheet and a color theme file (Colors.ts)
